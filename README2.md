# Supply Chain Operations Efficiency Dashboard (Tableau)

## Overview
Interactive Tableau dashboard analyzing 10,000+ supply chain orders to identify operational optimization opportunities.

## Live Dashboard
[View on Tableau Public](https://public.tableau.com/app/profile/nathaniel.harris8003/vizzes)

## Key Findings
- **Standard Class shipping**: 62% on-time, lowest cost ($51/day), best planning accuracy
- **First Class shipping**: Only 5% on-time, highest cost ($409/day), worst performer
- **Delivery improvement**: 97% faster over 3 years (85K → 2.9K days average)
- **Planning gap**: Second Class has 27K-day variance (requires process improvement)
- **Risk analysis**: Late delivery risk ranges from 40% (Standard) to 100% (First Class)

## Dashboard Features
- 4 KPI cards (on-time rate, late risk %, cost/day, delivery variance)
- Shipping mode performance comparison
- 3-year delivery time trend analysis
- Cost vs. speed scatter analysis
- Late delivery risk breakdown
- Planning accuracy by mode
- **Interactive filter**: Drill down by shipping mode in real-time

## Technologies
- Tableau Public
- Supply chain dataset (10,000+ orders)
- Operations efficiency metrics
